Introduction

aioshad is a high-performance, asynchronous Python framework for creating bots, self-bots, and automation workflows on Shad Messenger (شاد).

Unlike legacy scrapers and synchronous scripts that rely on single-threaded blocking requests, aioshad implements native HTTP/2 persistent streaming, reverse-engineered AES-256 and RSA-1024 encryption schemes, and an architecture directly inspired by aiogram 3.

Architecture Principle: aioshad connects natively to domestic Shad edge servers (*.iranlms.ir) without third-party middle-boxes or headless browser overhead.

Installation

aioshad is published on PyPI under the package name aioshad-py. Python 3.8 or higher is required.

Terminal 
pip install aioshad-py

Or using the uv package manager:

Terminal 
uv add aioshad-py

Quickstart

Below is a working minimal self-bot with an echo responder and a self-ping command:

main.py 
import asyncio
from aioshad import Client, F
from aioshad.filters import IsMe
from aioshad.types import Message

client = Client(session="my_account")

@client.on_message(F.text.startswith("echo "))
async def echo_handler(msg: Message):
    content = msg.text[5:].strip()
    await msg.reply(f"Echo: {content}")

@client.on_message(IsMe(), F.text == "!ping")
async def ping_handler(msg: Message):
    await msg.edit("Pong! aioshad is active.")

if __name__ == "__main__":
    client.run()

Session Storage

aioshad stores authentication tokens and cryptographic keypairs in persistent session files. Several backends are available:

  • FileSessionStorage: Default JSON-backed session saved at <session_name>.session.
  • SQLiteSessionStorage: Multi-session storage in a single SQLite file.
  • MemorySessionStorage: In-memory session suitable for ephemeral workers and unit tests.
sessions.py 
from aioshad import Client
from aioshad.session import SQLiteSessionStorage

storage = SQLiteSessionStorage("accounts.db")
client = Client(session="primary", storage=storage)

Security Advisory: Never commit *.session or *.db files to git. They are automatically ignored in the default .gitignore.

Dispatcher & Routers

Structure your application with modular routers instead of monolithic handler files:

routers.py 
from aioshad import Client, Dispatcher, Router
from aioshad.filters import Command, CommandObject

admin_router = Router(name="admin")

@admin_router.message(Command("ban"))
async def ban_handler(msg, command: CommandObject):
    await msg.reply(f"Target: {command.args}")

dp = Dispatcher()
dp.include_router(admin_router)
client = Client(session="my_account", dispatcher=dp)

Filters & Magic Filter F

aioshad includes built-in filters and Magic Filter expressions:

filters.py 
from aioshad import F
from aioshad.filters import Command, IsGroup, IsChannel, IsMe

@client.on_message(IsGroup(), Command("stats"))
async def stats_handler(msg):
    pass

@client.on_message(F.text.lower().contains("help"))
async def help_handler(msg):
    await msg.reply("Help documentation...")

Message API

The Message object offers convenient methods bound directly to the active client session:

  • await msg.reply(text): Sends a reply referencing this message.
  • await msg.edit(text): Edits this message in place.
  • await msg.delete(delete_type="Global"): Deletes the message for all members.
  • await msg.forward(target_chat_guid): Forwards message to another chat.
  • await msg.get_chat(): Retrieves parent Chat object.
  • await msg.get_author(): Retrieves author's User profile.

Conversation Manager

Use async with client.conversation(...) to execute synchronous-style dialogues without callback fragmentation:

conversation.py 
async with client.conversation(chat_guid, timeout=60) as conv:
    await conv.send_message("Enter access key:")
    key_msg = await conv.get_response()
    if key_msg.text == "secret":
        await conv.send_message("Access granted.")
    else:
        await conv.send_message("Access denied.")

Finite State Machine

For complex dialog states across user restarts, define states with StatesGroup and State:

states.py 
from aioshad.fsm import StatesGroup, State, FSMContext

class Registration(StatesGroup):
    name = State()
    phone = State()

@dp.message(Registration.name)
async def got_name(msg, state: FSMContext):
    await state.update_data(name=msg.text)
    await state.set_state(Registration.phone)
    await msg.reply("Enter phone:")

Media Upload & Download

Upload photos with automatic thumbnail generation, audio voice notes, and arbitrary files:

media.py 
await client.send_photo(chat_guid, "banner.jpg", caption="Announcement")
await client.send_file(chat_guid, "specs.pdf", file_name="Specifications.pdf")
await client.send_voice(chat_guid, "message.ogg")

if msg.file_inline:
    path = await client.download_file(msg.file_inline, destination="download.jpg")

WebRTC Voice Chat

Interact with group and channel voice chats via dedicated methods:

voice.py 
info = await client.create_voice_chat(group_guid)
await client.join_voice_chat(group_guid, voice_chat_id)
await client.change_voice_chat_voice_status(group_guid, voice_chat_id, voice_status=True)
users = await client.get_voice_chat_participants(group_guid, voice_chat_id)

Multi-Account Manager

Run dozens of concurrent sessions with ClientManager:

multi.py 
from aioshad.client.manager import ClientManager

manager = ClientManager(dispatcher=dp)
manager.add_client(session="acc1", phone_number="09121111111")
manager.add_client(session="acc2", phone_number="09122222222")
manager.run_all()

CLI Commands Reference

The official CLI executable aioshad provides rapid scaffolding and authentication:

Terminal 
# Initialize new modular bot project
aioshad init my_project

# Authenticate account & save session
aioshad login -s my_account

# Inspect session details (GUID, host, auth)
aioshad session-info my_account.session

Exceptions & Diagnostics

All exceptions derive from AioshadError:

  • AioshadError: Base exception for all framework errors.
  • NetworkError: Connection timeout, DNS failure, or HTTP/2 transport issue.
  • ShadAPIError: Non-OK API response from Shad backend.
  • InvalidAuthError: Invalid or revoked session token / wrong OTP code.
  • FloodWaitError: Rate limit exceeded; indicates wait seconds required.
