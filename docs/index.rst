aioshad documentation
=====================

``aioshad`` is a modern, blazingly fast, fully asynchronous Python framework & self-bot library for Shad Messenger (شاد), built on HTTP/2 multiplexing, native reverse-engineered cryptography, and an aiogram 3-style application architecture.
