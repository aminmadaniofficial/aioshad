📦 Installation

aioshad is distributed through PyPI as aioshad-py. It requires Python 3.8 or newer.

BASH
pip install aioshad-py

Or using the ultra-fast uv package manager:

BASH
uv add aioshad-py

💡 Domestic Network: Shad Messenger hosts are hosted within Iran (*.iranlms.ir). aioshad automatically optimizes connections directly to these gateways for maximum bandwidth and minimum latency.

⚡ Quickstart

Here is a complete, minimal selfbot responding to messages and personal commands:

PYTHON
import asyncio
from aioshad import Client, F
from aioshad.filters import IsMe
from aioshad.types import Message

# Initialize client with persistent session name
client = Client(session="my_account")

# Echo any incoming text message starting with "echo "
@client.on_message(F.text.startswith("echo "))
async def echo_handler(msg: Message):
    content = msg.text[5:].strip()
    await msg.reply(f"📣 {content}")

# Self command: only trigger if sent by you
@client.on_message(IsMe(), F.text == "!ping")
async def ping_handler(msg: Message):
    await msg.edit("🏓 Pong from aioshad!")

if __name__ == "__main__":
    client.run()

When running this script for the first time, you will be prompted to enter your phone number and OTP code. An authenticated session file (my_account.session) will be created for seamless subsequent runs.

🔐 Authentication & Sessions

aioshad supports multiple session storage backends:

  • FileSessionStorage (default): Stores JSON-formatted session state in <name>.session.
  • SQLiteSessionStorage: High-concurrency relational storage in SQLite databases.
  • MemorySessionStorage: Ephemeral in-memory storage ideal for tests and serverless jobs.
PYTHON
from aioshad import Client
from aioshad.session import SQLiteSessionStorage

# Store session in SQLite
storage = SQLiteSessionStorage("sessions.db")
client = Client(session="account_1", storage=storage)

🔒 Security Tip: Never commit *.session files to version control. Always include *.session in your .gitignore.

🧩 Dispatcher & Routers

For scalable architectures, separate your logic across multiple modular routers:

PYTHON
from aioshad import Client, Dispatcher, Router
from aioshad.filters import Command, CommandObject
from aioshad.types import Message

user_router = Router(name="users")

@user_router.message(Command("start"))
async def start_cmd(msg: Message, command: CommandObject):
    await msg.reply("Welcome to aioshad!")

dp = Dispatcher()
dp.include_router(user_router)

client = Client(session="my_account", dispatcher=dp)
client.run()

🎯 Filters & Magic Filter F

Filter updates effortlessly with built-in filters and fluent Magic Filter expressions:

PYTHON
from aioshad import F
from aioshad.filters import Command, IsMe, IsGroup, IsChannel, IsPrivate

# Filter by text prefix or content
@client.on_message(F.text.lower().contains("python"))
async def on_python(msg: Message):
    await msg.reply("Python rocks! 🐍")

# Group-only command
@client.on_message(IsGroup(), Command("rules"))
async def on_rules(msg: Message):
    await msg.reply("1. Be respectful\n2. No spam")

💬 Message Operations

The Message object offers convenient bound methods for chatting:

PYTHON
# Reply with text
await msg.reply("Reply text")

# Edit existing message
await msg.edit("Updated content")

# Delete message globally
await msg.delete(delete_type="Global")

# Forward to another chat
await msg.forward(target_chat_guid)

# Fetch chat metadata
chat = await msg.get_chat()
print(f"Chat Title: {chat.title}")

🧠 Conversations & FSM

Construct sequential, interactive dialogues with the conversation context manager:

PYTHON
@client.on_message(Command("survey"))
async def survey_handler(msg: Message):
    async with client.conversation(msg.chat_guid, timeout=45) as conv:
        await conv.send_message("What is your developer username?")
        username_msg = await conv.get_response()

        await conv.send_message("What is your favorite language?")
        lang_msg = await conv.get_response()

        await conv.send_message(f"Saved: {username_msg.text} enjoys {lang_msg.text}!")

👥 Multi-Account Orchestration

Manage multiple sessions concurrently with ClientManager:

PYTHON
from aioshad import Dispatcher, F
from aioshad.client.manager import ClientManager
from aioshad.types import Message

dp = Dispatcher()

@dp.message(F.text == "!status")
async def status_cmd(msg: Message, client):
    await msg.reply(f"Online! Client GUID: {client.me}")

manager = ClientManager(dispatcher=dp)
manager.add_client(session="bot_1", phone_number="09121111111")
manager.add_client(session="bot_2", phone_number="09122222222")
manager.run_all()

🛠️ CLI Commands Reference

aioshad bundles a developer command line tool for rapid setup:

BASH
# Scaffold a new modular project
aioshad init my_new_bot

# Log in and save credentials to session file
aioshad login -s my_account

# View session diagnostics
aioshad session-info my_account.session
